## 📊 Streamlit Dashboard

The project includes an interactive web-based dashboard developed using **Streamlit** to visualize network performance, packet-loss detection, future predictions, and machine learning results.

**🌐 Live Dashboard:** [Open AI-Based Packet Loss Detection and Prediction System](https://packet-loss-and-prediction-system-ng6ddfyibdhnfpgrkt4uhv.streamlit.app/)

### Dashboard Modules

- **System Overview:** Displays overall network statistics and packet-loss distribution.
- **Network Traffic Analysis:** Visualizes bandwidth utilization, RTT, jitter, throughput, and queue length.
- **AI-Based Packet Loss Detection:** Identifies current packet-loss conditions.
- **Five-Second Packet Loss Prediction:** Predicts potential packet-loss events in advance.
- **Machine Learning Model Performance:** Displays model evaluation metrics and comparison results.
- **Dataset Explorer:** Allows users to explore and download network measurement data.

### Dashboard 


The dashboard provides an interactive interface for analysing network behaviour, identifying packet-loss conditions, examining prediction results, and evaluating the performance of the trained machine learning models.
